TASK 01 · PHP

แสดงผลด้วย PHP

ทดลอง echo การเชื่อมข้อความ และ short echo tag

ตัวอย่างผลลัพธ์

สวัสดีโลก!

ยินดีต้อนรับ

สวัสดี สมชาย!

ชื่อของฉันคือ สมชาย

โค้ด PHP

<?php
// แสดงผลด้วย echo
echo "สวัสดีโลก!";
echo "<h1>ยินดีต้อนรับ</h1>";

// ใช้ . เชื่อมข้อความ
$name = "สมชาย";
echo "สวัสดี " . $name . "!";

// Short echo tag
?>
<p>ชื่อของฉันคือ <?= $name ?></p>
