เพิ่มทิปให้รายการสั่งซื้อ

PHP คำนวณราคารวม ส่วน JavaScript เพิ่มทิปเมื่อกดปุ่ม

รายการสั่งซื้อ

ลาเต้ x 3

รวม 135 บาท

โค้ด PHP และ JavaScript

<?php
$item  = "ลาเต้";
$price = 45;
$qty   = 3;
$total = $price * $qty;
?>
<p>ลาเต้ x <?= $qty ?></p>
<p>รวม <?= $total ?> บาท</p>

<script>
    const total = 135;

    document.getElementById("tip").addEventListener("click", function () {
        document.getElementById("grand").textContent =
            "รวมทิป " + (total * 1.1).toFixed(2) + " บาท";
    });
</script>

หน้า HTML นี้เปิดดูได้โดยไม่ต้องใช้ PHP server; โค้ด PHP ต้นฉบับอยู่ในไฟล์ Testp5.php
