LESSON 05 · PHP

พื้นฐาน PHP

ฝึกแสดงผล ตัวแปร ชนิดข้อมูล ตัวดำเนินการ ฟังก์ชันจัดการข้อความ และการใช้ PHP ร่วมกับ JavaScript

Task 1 · แสดงผลด้วย PHP ทดลองใช้ echo การเชื่อมข้อความ และ short echo tag Task 2 · ตัวแปรและชนิดข้อมูล ใช้ gettype(), var_dump() และค่าคงที่ Task 3 · ตัวแปรและค่าคงที่ ทบทวนชนิดข้อมูล การแทรกตัวแปรในข้อความ และ PI Task 4 · ตัวดำเนินการและ String คำนวณตัวเลข จัดการข้อความ และจัดรูปแบบราคา Task 5 · PHP และ JavaScript คำนวณราคารวมด้วย PHP และเพิ่มทิปด้วย JavaScript
