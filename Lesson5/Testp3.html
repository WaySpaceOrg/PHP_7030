TASK 03 · PHP

ตัวแปรและชนิดข้อมูล

ตัวแปรขึ้นต้นด้วย $ และชื่อตัวแปรแยกตัวพิมพ์ใหญ่-เล็ก

ตัวอย่างผลลัพธ์

stringint(30)
ชื่อ: สมชาย อายุ: 30 ปี3.14159

โค้ด PHP

<?php
$name   = "สมชาย";       // String
$age    = 30;              // Integer
$gpa    = 3.75;            // Float
$active = true;            // Boolean
$note   = null;            // NULL

echo gettype($name);       // string
var_dump($age);            // int(30)

// String interpolation (ใส่ตัวแปรใน "")
echo "ชื่อ: $name อายุ: $age ปี";

// Constants
define("PI", 3.14159);
echo PI;

หน้านี้แสดงตัวอย่างแบบ static; หากต้องการให้ PHP ประมวลผลจริง ต้องเปิดไฟล์ Testp3.php ผ่าน PHP server
